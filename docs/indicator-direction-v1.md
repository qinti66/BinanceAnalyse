# 合约指标方向研判 v1

每币显示偏多（多头观察）、偏空（空头观察）或观望。列表参数分析和详情共用 lib/indicators/direction.ts，交叉验证也复用此函数。只读取已保存快照，不新增采集、调度、交易。定时检查本地时间仅撤销过期标签。

## 自定义研究规则（不是币安推荐参数，尚未回测）

1. 先校验数据、流动性、时间：完整性达标，24h成交额≥500万美元、整点OI市值≥100万美元、价差≤25bps；快照≤6h；价格、IO、OI、量比、RSI、ATR、价差可用。主合约为永续时要求资金费率可用。
2. 多头结构：4h涨幅≥1%、4h主动净流比≥8%、1h价格>EMA20>EMA60；空头结构完全反向。
3. 参与度确认：4h OI增加≥3%，或4h成交量比≥1.5倍，至少一项。OI自身不提供多空方向。
4. 以下任一情况改为观望，不反向开仓：OI减少≥3%；多头RSI≥75或空头RSI≤25；1h ATR/价格≥5%；同向24h等效资金费率≥0.1%；OI/流通市值≥50%；没有参与度确认。
5. OI/流通市值≥20%附拥挤警示；市值比例缺失保留未知风险，不视为0。未触发门槛不代表无风险。
6. 全部百分比门槛使用百分数值，非小数比例；关注分不参与方向计算，不输出预测胜率。

快照价格/OI/成交按整点对齐；资金费率、价差等是本轮采集的较新风险观察，不冒充所有指标同刻实盘。默认是过去4h结构研判，不是未来4h收益预测，也不是下单指令。
