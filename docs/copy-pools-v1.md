# 合约带单双池 v1

## 已确认需求

系统按证据给合格组合打“优质聪明钱 · 候选”标记，进入优质池；其余保留普通池。
可以独立更新任一池，也可以更新两个池。周期偏好可分别设置，但按用户本次确认，自动更新关闭：无操作系统任务、无 Codex 自动化、无后台采集计时器。
个人关注星标与系统评级互相独立，关注不会直接晋级。

## 页面与运行

- 路由 /copy-trading；三个模块互有导航。
- Node 24：node scripts/copy-pool-service.mjs（本机8792，仅手动触发）。
- 本地页面：node scripts/run-framework.mjs dev --hostname 127.0.0.1（5173）。
- 命令行手动更新：node scripts/update-copy-pools.mjs all、quality 或 ordinary。
- 只复核失败成员：node scripts/update-copy-pools.mjs retry（不伪称整池重新更新）。
- 本地重分析：node scripts/analyze-copy-pools.mjs。可显式传入已停止的批次目录名，合并该批次已完成的成员文件；保留整池原时间，并标记限流中断，绝不宣称全池刷新成功。
- 初始历史导入：node scripts/import-copy-pools.mjs，仅用于首次建立本模块；会重新初始化双池，不要在已有分池历史上重复运行。
- 测试：node --test scripts/test-copy-pools.mjs。
- 周期与星标持久化在当前浏览器 localStorage，不承诺跨浏览器同步。页面每分钟只重算标记有效性；仅在手动采集已经启动时轮询服务进度。

## 来源和范围

币安公开网页 BAPI：home-page/query-list、lead-portfolio/detail、lead-portfolio/order-history。不是稳定的正式开放 API，不使用账户密钥，不跟单或交易。401/403/418/429 停止，不绕过。
四个周期7/30/90/180天、七种榜单各前50名取并集，再保留已有池成员。不是全部带单员，也不是无偏样本。获取详情及30/90天业绩；排行榜未命中时以公开昵称查询并严格匹配组合ID。
订单每页100条，最多100页；返回不足、总数变化或末次复查第一页变化都标记不完整，不强行升为优质。
公开资料不能保证捕获整个账户一生的历史；“完整”仅表示本次公开分页一致。

## 评级：全部门槛同时通过

1. 资料在48小时内且读取成功；活跃UM组合，公开订单，本次分页完整。
2. 运行≥90天；30天和90天ROI、PNL、跟随者PNL均正。这些滚动区间重叠，并非独立重复验证。
3. 30天MDD≤25%、90天MDD≤35%；30天夏普≥0.5。
4. 可重建完整周期≥30个、订单跨度≥14天、亏损周期≥3个。
5. 无无效/方向不明/疑似重复订单，无同毫秒开平先后歧义；支持USDT/USDC近似美元。未配对平仓比例≤5%。
6. 持仓中位数≥5分钟，5分钟内平仓≤30%；利润因子≥1.2，最大盈利周期占总盈利≤35%。
7. 异常筛查分<25，1分钟内同向重开≤25%。

质量门槛通过率仅便于查验，不是盈利概率。阈值是本项目初始启发式规则，未回测，不等同币安 Smart Filter 或官方精英等级。没有达标者时优质池为空，不自动放松条件。

## 持仓与异常计算

按组合ID＋合约＋LONG/SHORT重建数量归零周期；支持加仓和部分平仓。BOTH不凭零PNL推测开平。
每个品种/方向第一个周期边界不明，排除；未匹配平仓不创造利润，未归零残留不计已平仓周期。订单更新时间是聚合级近似，不是逐笔成交时间。
首周期排除仍不能证明后续所有历史完全无遗漏，所以只有“候选”标记。无订单ID的完全相同记录保留并标为歧义；同刻同向加仓不误报为开平顺序歧义。
观察一分钟/五分钟内平仓、快速重开/反向、等量且近零利润回转、双向重叠；双向重叠可能为合法对冲，不直接罚分。
不能凭公开记录判断对手账户或对刷关系。异常分为复核信号，不是舞弊概率。
利润因子用可重建周期订单PNL，未确认扣尽手续费/资金费；不叫净收益。没有亏损时显示缺失，不以无穷大加分。
平台收益和风险指标是整个组合口径，可能包含传统资产合约；没有把组合总ROI冒称为纯加密货币收益。
当前仓位接口尚未接入；残留开仓只显示为未闭合订单，不用于声称当前聪明钱正在买某币。

## 更新、升降池和持久化

单池更新以任务启动时的有效成员为集合，另一池的记录与处理时间不改；评级可能导致成员跨池。
全池更新另做候选发现。隐藏记录、失败、数据不全、风险/业绩不达标降入普通池；每行保留实际采集时间。48小时后页面暂停旧优质标记，无需重新访问币安。
保留逐条入池/升降级原因，页面只展示最近30条，快照保存最近500条。
data/copy-trading 保存规范化记录、日期批次、公开响应、请求清单和锁；public/copy-trading/latest.json 保存页面快照。失败不覆盖旧页面快照；单个组合失败保留旧证据并取消优质资格，来源错误显式展示。
采集并发2，共享350ms请求节奏；仅临时忙碌代码11012005按1.5秒、4秒最多重试两次。HTTP 401/403/418/429、API 90801003及请求过多提示直接停止，不绕过限制。文件锁防止重复任务；异常退出遗留锁须确认进程已停止后人工处理。
本地服务只监听127.0.0.1，限制Origin和Host，只接受固定scope，无任意命令执行。生产站点不能调用本机更新。
本模块暂不改写原有融合结论；未来按evidenceId去重接入，不能将广场晒单和带单同一仓位算作两份独立资金支持。
