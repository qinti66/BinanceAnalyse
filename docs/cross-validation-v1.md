# 可选交叉验证与一次性真实采集

本机入口：/cross-validation。顶部三个模块仍保持同排，另有交叉验证入口；/ 保留旧版固定快照，旧数据不参与新版计算。

## 功能

- 勾选任意两个或三个模块，即时重算；不足两个时不显示结论。
- 四种组合均可使用：广场×指标、广场×带单、指标×带单、三者。
- 支持单独更新、更新所选、全部更新一次。无定时任务，无交易操作。
- 8791 指标服务、8792 带单服务、8793 广场服务，均只接受本机页面的手动请求。
- 保留来源、分析截止时点、每模块快照时间，区分同向、冲突、混合与证据不足。

## 数据与口径

广场：币安公开 article/list 的热门 type=1（最多10页）和最新 type=2（最多50页），每页20条，最新列表达到24h边界停止。不是全站全量；结果保存原始响应、分页终止原因与回执。只保留24h内且币安结构化标签能映射到已有合约目录的帖子。多币种帖子分别归属，单作者每币种只投一次。情绪使用保守中英关键词规则，不明确、疑问、条件及冲突表达不推断方向。不是完整 NLP，不支持的语言不伪造标签。

原帖分享卡单独展示，遵守 showAmount/isShowPNL 的公开设置；没有独立当前仓位及发帖前证据，不提升权重。分享卡数值不是当前实仓证明。当前快照无此核验证据时，仓位加分可以为零。

指标：使用既有真实采集器；价格、主动买卖 IO、OI 对齐整点。完整性与流动性门槛通过后，4h 价格≥1%且 IO 净流比≥8%为偏多；反向为偏空；其余为混合。OI 本身不是净多资金。

带单：按所选池筛选，额外要求分页公开完整、订单完整性达标、异常筛查分已知且低于25、资料及订单时间均在6h内；普通池也不绕过证据门槛。每个账户每个币种仅取分析截止前24h最近完整平仓周期。严格使用合约目录映射，未映射合约排除。至少两位带单员，多空人数差占比达到34%才有方向。只反映已平仓历史，不代表当前持仓。普通池仅作探索，不称为优质聪明钱。

时效：使用指标整点作为截止；不含指标时取所选快照较早时间向下取整点。帖子及平仓时间不得晚于截止。来源需覆盖截止且观察在6小时内。广场至少3位作者、2位方向明确，净情绪±15%为阈值。任一所选模块不达标则证据不足；中性不制造共识。旧快照保留原时间；本轮服务明确失败或读取失败的模块不参与当前交叉计算。

交叉只比较方向，不叠加仓位加分，也不生成收益保证或买卖建议。广场作者与带单账户尚无完整身份映射，因此不声称跨模块证据完全独立。所有门槛待回测。
