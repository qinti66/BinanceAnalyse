# 结论文档 v1：概率判断面板的判别力探索（截至 2026-09-23）

> 写给没有上下文的读者。本文档是 T34-T40 这一轮探索的合并结论，细节与逐次数字见 `docs/calibration-log-v1.md`（同一批 T 编号）。

## 一、有什么

**先说一次重要的数据修正**：最初的 526 个合约全部是**当前仍在交易的存活合约**。但自 2024-09 以来，约有 121 个合约（约占宇宙的 23%）已经下架——这意味着最初的实验系统性地缺掉了"这个币看起来像要启动、结果被下架"这类最坏的结果。这一轮把能取得数据的 121 个里的 81 个补了回来重新实验，并把"至少要补入多少比例"写进了质量门禁（默认不通过，见下文"已知偏差清单"）。以下结论均基于补入后的完整实验。

用一个最简单的指标——**`d1_vol_squeeze_pct`（当前 ATR 压缩分位数）**——按数值从低到高给 645 个币（含上述 81 个已下架合约）的每日决策点排序：

- 最压缩的那 10%（十分位 1）里，24 小时内**实际发生"异动"**（价格走出 ±2.449×ATR，已扣除往返交易成本，含点差与滑点）的比例是 **86.6%**；
- 最不压缩的那 10%（十分位 10）只有 **54.0%**；
- 整体基础率是 **70.8%**；
- 曲线单调，按天聚类自助法给出的置信区间稳固（最高档相对基础率的提升 +15.7 个百分点，95% CI [13.7pp, 17.7pp]）。

**这验证了项目最初的核心假设——"蓄势之后启动"——是对的。** 只是能捕捉到它的，是一个最朴素的波动率压缩分位数，不需要训练模型，不需要校准，甚至不需要 SMC / Wyckoff / 缠论衍生出的那些结构特征。

## 二、没有什么

1. **不能预测方向，而且是负优势，不只是"没优势"。** 全市场基础率里，涨比跌略占优（down 34.6% / up 36.2%，倾斜 +1.6 个百分点）；但按模型判断"最可能涨"去挑出的那 10% 决策点里，这个倾斜反而**翻成了负的**（down 42.3% / up 41.5%，倾斜 −0.8 个百分点）。去掉大盘影响的残差标签下同样如此（基础率倾斜 +4.2pp → 挑出来的最高档倾斜 +3.1pp，虽然还是正的，但比不挑还差）。十分位提升度检验确认模型对"涨"确有排序力（最高档 up 的实际发生率明显高于基础率，曲线单调），但这个分数测的是"会不会动"，不是"往哪动"——**按预测的"涨"去挑选，涨跌对比会比什么都不挑更差，哪怕反着用（挑"最不像涨"的）也不能当方向信号使用。**

2. **那 20 个额外特征（含我们精心挑选保留的结构特征组）目前测不出可测量的增量。** 用完全相同的折、标签、训练设置做嵌套对比：仅 1 个特征（d1）比 3 个特征（压缩组）比 21 个特征（全部）——BSS 点估计**单调递减**（21 特征反而最低），置信区间高度重叠。独立的理论测算（有效样本数约 360 天，21 特征二分类需要约 440 个才不过拟合，实际不够；1 特征只需约 40 个，远够）与这个方向一致，而且这条充足性规则是在看到任何结果之前就定好的。

3. **概率的"校准"（让输出的百分比数值本身准确）不能跨时间稳定迁移。** 试了两种方法（等渗回归、Platt 缩放），都让判别力（BSS）明显下降，包括理论上不该影响排序的 Platt 缩放也是如此——唯一说得通的解释是"分数与实际结果的映射关系会随时间漂移"，用某段历史校准出来的映射，到了后面的时间段就不准了。

## 三、这个结论是怎么来的（这段本身是结论可信的前提）

这一轮探索反复出现同一个模式：**先往模型里加东西 → 在看到结果之前先把判读规则写死 → 诚实地跑数据 → 按写死的规则决定去留**。四次独立的"加东西"，四次都是加了之后变差：

```
21 特征 (BSS 0.0326)  <  3 特征 (0.0365)  <  1 特征 (0.0390)
1 特征 + 等渗校准 (0.0106)  <  1 特征（不校准）
1 特征 + Platt 缩放 (0.0227)  <  1 特征（不校准）
训练出来的模型排序  ≡  直接按原始 d1 排序（逐点相差 ≤0.3 个百分点）
```

过程中还发现并修复了一个真实的工程 bug（已下架合约查不到实时价差，导致其标签几乎全部丢失，一度被误判为"含下架合约后结论不变"），以及一次门禁定义的调整（下架合约覆盖率的分母，从"全部已识别 121 个"改为"与决策窗口有重叠的 87 个"——这是第二次在门禁失败之后修改定义，两种口径的数字都留了档，改动理由独立于结果本身可以核实）。

**泄漏检查是干净的，这是上面正面结论能站得住的前提**：随机特征基线（按日聚团抽样）约等于 0；把标签打乱但保留时间结构后重新训练，判别力同样约等于 0，判定为"clean"；按天块整体置换标签的零假设分布，中心在 **−0.0088**（把 21 个特征硬拟合到纯噪声标签上，样本外平均会**亏掉**约 0.0088 的 BSS），真实观测值比这个零假设中心高出约 **3.4 个标准差**。这一条必须单独说清楚：**"BSS 大于 0"这个门槛，实际上比"跑赢纯噪声"更严格**——零假设本身就是负的，不是摆在 0 上，接近 0 的数字不能简单读作"没有信号"，要跟这个负的零假设中心比。

**显示精度不能超过校准精度，这是不建议显示成精确概率、而建议显示成排名的技术理由（不是审美偏好）**：按"半个显示步长 ≥ ECE"这条经验规则算，原始三分类模型 ECE=0.0538，连粗略的 10% 档位都不够诚实地显示；本方案（仅 d1，不做校准）ECE=0.0166，大约能诚实显示到 3-5% 的粒度。而如果显示成**排名**（"这个币比另一个币更接近临界点"），只需要排序单调，不需要数值本身准确——上一节已经说明单调性是稳的（原始 d1 排序几乎完全复现了训练出来的模型排序），而校准（数值准确性）是不稳的（等渗回归、Platt 缩放两种方法都让分数变差，且发现校准映射不能跨时间段迁移）。这是选择"排名"而不是"精确概率"这个显示形态的技术依据。

## 四、为什么现在还不能上线

**以上全部结果都是探索性的，不是可以直接部署的结论：**

- "会不会动"这个二分类重述，是**看过原始三分类的结果之后**才想到的假设；
- 同一批测试折在这一轮里被反复查看了十几次；
- 按项目一贯的规矩，这种情况下得出的效应必须在 **2026-09-23 之后新采集的数据**上做前瞻验证，才能算数，不能直接进门禁或上线。

## 五、已知偏差清单（不合并，逐条列出）

- 点差按**今天**的实时快照计算，套用到过去两年的历史交易日——历史上的真实流动性通常更差，这个简化对存活合约偏乐观。
- 已下架合约没有"今天的价差"可用，替代值取**存活合约当前价差分布的 p90**——这是一个判断值，不是实测值；做了 p50/p90/p99 三档敏感性检验，结论在三档间不翻转，但这仍然是"两边都软"的成本模型的一部分，不是精确值。
- 下架合约覆盖率门禁的分母口径改过一次（详见上文），两种口径的数字都留了档。
- 有效独立样本数（按天聚类）约 360 天，远小于表面上的 16.7 万行——这是本轮多次判读（充足性规则、置信区间、过拟合判据）背后的关键前提。

## 六、这个工具现在数据能支持做成什么

**数据支持的形态**：一个"**异动临近度**"排名——按 `d1_vol_squeeze_pct` 从低到高给币种排序，回答"哪些币的波动正在压缩到接近历史极值、可能即将脱离横盘"。这是本轮唯一测出稳固、单调、有置信区间支撑的信号。

**数据不支持的形态**：任何方向性输出——"做多可行性"、"做空可行性"、涨跌概率——都不该做。原因见第二节第 1 条：按模型判断挑出的"最可能涨"币种，实际涨跌对比比不挑还差，这不是精度不够的问题，是这个分数本身不携带方向信息。

**结构类读数（SMC/Wyckoff/缠论衍生特征）如果还要在面板上显示，必须注明"未测出增量预测力"**——第二节第 2 条的嵌套对比显示，这些特征加进模型后判别力没有变好、反而单调变差。不加这句注明，显示这些读数这个行为本身就是在暗示一个已经被这轮实验证伪的价值。

## 七、建议（供用户决策，不由我们替你决定）

- 数据采集**不要停**：币安合约行情/资金费率接口只保留约 30 天历史，今天不采的窗口以后永远补不回来。模型现阶段用不上不等于这些数据没价值——保留下来的成本很低，将来想重新论证时能用得上。
- 若要继续这条"排名/相对强弱"的方向，下一步是等一段新数据积累后做前瞻验证，而不是在现有测试折上继续挖。
